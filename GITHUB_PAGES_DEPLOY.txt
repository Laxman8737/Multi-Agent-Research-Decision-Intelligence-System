GitHub Pages quick setup for multi-agent-research-system

1. Extract this ZIP.
2. Create a GitHub repository named multi-agent-research-system (or your preferred name).
3. Upload the CONTENTS of this extracted folder to the repository root. Do not upload only the ZIP file.
4. Commit to the main branch.
5. Repository → Settings → Pages → Build and deployment → Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for deployment and open the exact URL shown by GitHub Pages.

The static demo runs in recorded mode on Pages. For live API features, run the Python app with: python run_local.py

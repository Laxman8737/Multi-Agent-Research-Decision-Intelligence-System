ARCHITECTURE

Question→Planner→Researcher (tool calls)→Extractor + injection quarantine→Verifier→Conflict detector→Cited report

Agents share a state dict (LangGraph-compatible). Tools are schema-validated like LLM function calls. Every run returns a trace, tool-call log and token/cost usage.

LIMITATIONS

  • Reference agents are rule-based (regex claim grammar, token-set subject keys): synonyms such as “EV” vs “electric vehicle” are missed, which is visible in the eval numbers.
  • Verification is cross-source agreement; correlated sources that copy each other would look corroborated. No source-credibility weighting yet.
  • Evidence is a small synthetic corpus; the only live tool is corpus search. A web tool would need allow-listing and SSRF protection.
  • LLM-based planning/extraction and LLM-as-judge are provided as extension points but were not run in the bundled evaluation.
  • No persistence, per-user auth or rate limiting.
